# AI Studio 🎨

> **Created by Antono**


![AI Studio Banner](https://images.unsplash.com/photo-1677442136019-21780ecad995?w=800)

AI-powered creative studio for generating and editing content.

## ✨ Features

- 🤖 AI image generation
- 🎨 Style transfer
- 📝 Text-to-image
- 🖼️ Image editing
- 🎬 Content creation

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/antono4/ai-studio.git

# Open in browser
cd ai-studio
open index.html
```

## 📁 Project Structure

```
ai-studio/
├── index.html      # Main page
├── css/            # Stylesheets
├── js/             # JavaScript files
└── assets/         # Static assets
```
